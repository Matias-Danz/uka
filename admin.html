UKA – správa dat

Staré přihlašování pomocí GitHub tokenu bylo z bezpečnostních důvodů vypnuto. Tato stránka nikdy nepožaduje přístupový token.

Události a ruční úpravy spravuj přes GitHub: otevři soubor admin_overrides.json nebo availability_overrides.json, klikni na tužku (Edit), uprav JSON a potvrď změnu přes Commit changes. GitHub ověří tvoje přihlášení a oprávnění k repozitáři.

Po změně proběhnou validační testy. Chybný JSON nesmí projít publikací.
